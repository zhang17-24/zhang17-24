### ✍️ clean-* 系列的理念

> 市面上很多教程一上来就讲源码,新手根本看不懂。我想换一种方式:
> **先讲清楚"它为什么存在",再讲"它怎么工作"**。
> 每个 clean-* 项目都是一份可运行、带注释的最小实现,配合文章循序渐进。
